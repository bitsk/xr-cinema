# 《浮灯渡》和《极夜冰湾》

这两段动画和双声道配乐均为本播放器原创的程序化作品。《浮灯渡》在暮色湖面上展示不同距离的纸灯、荷叶与倒影。《极夜冰湾》环绕观众布置浮冰、雪脊、星空与极光。每部使用同一个左右眼镜头制作 SBS 和 TB 两版，方便在影院中对照排列方式。

## 制作

以 Python、NumPy 和 Pillow 在等距柱状画布上绘制远景。用周期函数构造山脊和极光幕，以固定种子布置星点、纸灯、荷叶、花瓣和切面的浮冰。两段动画的近景随机种子分别为 15201 和 36316。摄像机以 12 秒为周期在水面上方轻移，灯具随相位漂浮，浮冰缓慢转动。倒影由水面镜像几何生成。配乐由正弦泛音、衰减钟声与低通噪声合成。

左右眼基线为 64 毫米，每个经度使用各自的水平相切眼位。以正前方为 +Z，空间点相对摄像机中心的水平距离为 `r = hypot(x, z)`，中心经度为 `φ = atan2(x, z)`。对每个世界空间顶点分别以左眼 `e = −0.032` 米及右眼 `e = +0.032` 米计算经度 `φ − asin(e/r)` 和纬度 `atan2(y, sqrt(r²−e²))`。将两次投影独立光栅化。360° 版本在背后经线环绕绘制跨界网格。天空与远山作为无限远背景。[全向立体投影几何](https://developers.google.com/static/vr/jump/rendering-ods-content.pdf)

以 FFmpeg 和 libx264 编码原始排列，用逐眼裁剪和拼接生成对照排列，两次使用相同的 AAC 音轨。MP4 的 `st3d` 记录眼序，`sv3d/proj/equi` 记录投影。180° 片从完整经度左右各裁去四分之一，360° 片保留完整球面。[Spherical Video V2 元数据格式](https://github.com/google/spatial-media/blob/master/docs/spherical-video-v2-rfc.md)

## 交付校验

使用 `ffprobe -show_streams` 核对四片均为 12 秒、24 帧/秒、288 帧 H.264 YUV420P，音轨均为 44.1 kHz 双声道 AAC。立体元数据与表内排列一致，眼序均为左眼优先。

在第 4 秒解码左右眼灰度图，按水平位移搜索对应近景边缘。两种排列下，纸灯的两个特征区分别测得 3 与 4 像素视差，浮冰的两个特征区分别测得 3 与 2 像素视差。将同一场景的 SBS、TB 拆回独立眼图，逐眼平均绝对灰度差为 0.30 和 0.49 个 8 位灰度级。
